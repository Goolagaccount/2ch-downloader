# 2ch Downloader

**Картинки и видео из треда — в одну папку.**

Небольшая программа для Windows с простым графическим интерфейсом. Скачивает изображения и видео из тредов раздела **/b/** на 2ch.

### [↓ Скачать для Windows (.exe)](https://github.com/Goolagaccount/2ch-downloader/raw/refs/heads/main/2ch_downloader.exe)

[Посмотреть исходный код (PowerShell)](https://github.com/Goolagaccount/2ch-downloader/blob/main/2ch_downloader_%D0%B8%D1%81%D1%85%D0%BE%D0%B4%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4.ps1)

## Как пользоваться

1. Скачайте и откройте `2ch_downloader.exe`.
2. Вставьте ссылку на тред вида `https://2ch.su/b/res/123456.html`. Ссылки с параметрами и `#` тоже поддерживаются.
3. Выберите существующую папку через «Обзор…» и нажмите **«Скачать»**.

Файлы сохраняются в подпапку `thread_<номер треда>`. Там же находятся список ссылок `file_links.txt` и, при ошибках, журнал `errors.txt`. Уже существующие файлы пропускаются. Во время загрузки окно можно свернуть.

## Что важно знать

- EXE пересобран из опубликованного исходника. Поддерживаются разные домены и перенаправления; адрес зеркала указывается вручную.
- Нужны Windows и Windows PowerShell 5.1. macOS и Linux не поддерживаются.
- Текущая версия рассчитана на **/b/** и изображения/видео; PDF, DOCX и другие документы не скачивает.
- Исправлены завершение загрузки, сообщения об ошибках сети и повторный запуск. Сборка проверена на нейтральном локальном сервере; подробности и команды — в [BUILD_AND_TEST.md](BUILD_AND_TEST.md).

Скачивайте только материалы, которые имеете право сохранять. Лицензия на код пока не выбрана.
