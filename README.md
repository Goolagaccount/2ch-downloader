# 2ch Downloader

**Все вложения треда — в одну папку.**

Небольшая программа для Windows с простым интерфейсом. Скачивает PDF, документы, текст, архивы, изображения, видео и другие вложения из разных разделов 2ch.

[Посмотреть исходный код](https://github.com/Goolagaccount/2ch-downloader/blob/main/2ch_downloader_%D0%B8%D1%81%D1%85%D0%BE%D0%B4%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4.ps1)

## Как пользоваться

1. Скачайте и откройте `2ch_downloader.exe`.
2. Вставьте ссылку на тред, например `https://2ch.su/pr/res/123456.html`. Параметры и `#` поддерживаются.
3. Выберите папку через «Обзор…» и нажмите **«Скачать»**.

Вложения сохраняются в подпапку `thread_<номер треда>`. Там же находятся список `file_links.txt` и, при ошибках, `errors.txt`. Непустые существующие файлы пропускаются. Окно можно свернуть.

## Что важно знать

- Нужны Windows и Windows PowerShell 5.1.
- Поддерживаются HTTP/HTTPS и разные зеркала; адрес указывается вручную.
- Программа выбирает ссылки из блоков вложений треда. Посторонние ссылки из текста и меню не скачиваются. Привязки к `/b/` и списку расширений медиа больше нет.
- Файлы только сохраняются — программа их не запускает и автоматически не открывает. Опасные и служебные имена пропускаются.
- EXE пересобран и проверен: PDF, текст, ZIP, DOCX, медиа, другой раздел, повторы и ошибки сети. [Сборка и результаты тестов](BUILD_AND_TEST.md).

Скачивайте только материалы, которые имеете право сохранять. Лицензия на код пока не выбрана.
