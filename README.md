# 2ch-downloader

Небольшая программа для Windows: графический интерфейс PowerShell для скачивания изображений и видео из треда 2ch.

## Файлы

- `2ch_downloader_исходный код.ps1` — исходный скрипт, сохранён без изменений в исходной кодировке UTF-16 LE.
- `2ch_downloader.exe` — предоставленная автором сборка для Windows. В ней статически обнаружен полный текст приложенного скрипта; это не доказывает эквивалентность всего бинарника или его безопасность. Бинарник не запускался, независимый аудит и воспроизводимая сборка не выполнялись.

## Использование исходника

Windows и Windows PowerShell 5.1 с Windows Forms. Откройте скрипт для проверки перед запуском, затем запустите его в PowerShell в соответствии с политикой выполнения вашей системы. Укажите URL треда вида `https://2ch.hk/b/res/<ID>.html`, выберите существующую папку и нажмите «Скачать».

Программа создаёт подпапку `thread_<ID>`, сохраняет `file_links.txt` и журнал `errors.txt` при ошибках. Уже существующие файлы пропускаются; для скачивания предусмотрено до трёх попыток. Используйте отдельную папку вне репозитория и скачивайте только материалы, на которые у вас есть право.

## Ограничения текущей версии

- Поиск ссылок жёстко привязан к `/b/src/<ID>/`; другие доски и изменённая разметка могут не поддерживаться.
- Поддержаны JPG/JPEG, PNG, GIF, WEBP, BMP, TIFF, MP4, WEBM, MOV, AVI, MKV, FLV, WMV, MPEG/MPG. PDF, DOC/DOCX и другие документы в текущем фильтре отсутствуют.
- В ветке очистки журнала есть выражение `Test-Path $errorsFile -and ...`, способное вызвать ошибку параметра PowerShell; исходник опубликован как предоставлен, без исправлений.
- Проверка перед публикацией была статической. Работоспособность на Windows и скачивание с сайта не тестировались.
